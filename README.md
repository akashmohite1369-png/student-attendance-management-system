# Attendly — Student Attendance Management System

Deployment-ready mini-project for Engineering Semester 03 attendance management.

Subjects: AOA, COA, MATHS-3, DSGT, FSGT, ESE, ED.

## Public architecture
Browser → Netlify frontend → `/api` proxy → Render Java/Spring Boot API → H2.

## Local stack
- Frontend: HTML, CSS, JavaScript
- Backend: Java 21, Spring Boot 3.3.5, Spring Data JPA, Hibernate
- Database: H2
- Build: Maven 3.9+
- Deployment: Netlify + Render

Read `DEPLOYMENT.md` for the exact public-hosting steps.
